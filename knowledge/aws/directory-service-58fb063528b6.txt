AWS Directory Service
Troubleshooting hybrid directory and directory assessment
A directory assessment is required to create a hybrid directory. Assessment tests run on each domain controller. The
        assessment tests examines different areas and result in a
Passed
or
Failed
status. If your directory assessment fails, you can view the assessment tests of your
        domain controllers to identify what issues caused the failure.
Important
A hybrid directory can be created when the directory assessment's status is
Passed with
                warning
. We recommend you address the issue causing the warning prior to
            creating a hybrid directory

Troubleshooting failed hybrid directory assessment
You can troubleshoot a failed directory assessment from the
Directories
page in
            the AWS Management Console.
Sign in to the AWS Management Console and open the Directory Service console at
https://console.aws.amazon.com/directoryservicev2/
.
Under the
Directory assessments
section, select the
                    failed hybrid directory assessment.
On the
Assessment Details
page, review the directory assessment and
                    identify what test(s) failed.
The domain controller's assessment tests will have more information on what
                            tests were successful or failed. The
Status
column
                            provides more details on what caused the failed test. To view your
                            domain controller's assessment tests, see
Viewing directory assessments
.
Resolve the issues causing the failures on your self-managed Active Directory or
                    AWS Managed Microsoft AD. See
Directory Assessment Error Messages
and
Assessment Test error messages
for more information.
Return to the failed assessment in the Directory Service console. Choose
Create
                        assessment
in the red warning message. See
Creating a hybrid directory with your self-managed AD
for more information on creating
                    a directory assessment.
